# University Library Management System (Bachelor's final project)

Bachelor's final project documenting and customizing a university-library deployment based on Koha.

![Koha staff login in the local deployment](images/koha-staff-login.png)

## Verified artifacts

- `customizations/opac.css`: submitted OPAC visual customization.
- `customizations/opac-main-user-block.html`: submitted carousel/user-block customization.
- A reviewed screenshot of the local Koha staff login page with empty credential fields.

The source material documents analysis, UML design, Koha installation/configuration, an OPAC, staff workflows, mobile views, cataloguing, circulation, reservations, members, reports, and course reserves. This repository includes only the attributable customization samples, not the Koha application itself.

## Installation and use

Install a compatible Koha deployment following the official Koha documentation, then apply the CSS and user-block snippets through the OPAC system preferences/customization interface. Review all hard-coded `localhost` links and bibliographic identifiers before use.

## Excluded material

Member/database imports, MARC records, live-site snapshots, downloaded dependencies, institutional contact blocks, reports with extensive embedded material, and third-party assets were excluded. No database dump or credentials are present.

## Limitations

The original Koha version is not recorded clearly in the selected files, and the deployment could not be reconstructed in the Windows preparation environment. The carousel references example localhost records and remote cover images, so it is an archival customization sample rather than a turnkey theme.
